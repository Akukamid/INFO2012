Data Protection Notice

With the supplied JavaScript running, submitting displays a local summary and sends no form data. Passwords are masked in that summary, but the original input value remains readable through browser tools. Client-side checks can be bypassed; a real service also needs server-side validation, secure authentication and password storage.
